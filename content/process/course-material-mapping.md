# Course Material Mapping

*A process entry within [Process](/process/).*

> file by file, then read start to finish.

Raw material gets indexed at the file level before anything gets written from it, then read back in its native sequence rather than by topic. Sequence carries information a keyword search misses.

Notes get taken continuously while reading, curated down after.

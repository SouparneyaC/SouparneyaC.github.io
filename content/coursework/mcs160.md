# MCS160 — Introduction to Computer Science

> a project framed as hedge-fund strategy comparison turned out to implement a two-sample significance test from scratch, the same statistical reasoning that shows up a year later in actual quant research.

## Overview

MCS160 is UIC's Introduction to Computer Science, four credit hours, taught in Python, a general-education course that also carries the Illinois Articulation Initiative's equivalence for Computer Science I. I took it Fall 2025 under Gene Yoffe. Grades were built from two in-class exams, a cumulative final, three programming projects, and weekly quizzes and homework, with the exams alone worth more than half the final grade.

## What the course covered

The first two weeks stay below the level of actual Python syntax: number systems, decimal, binary, hexadecimal, Boolean algebra, and logic gates, how a computer represents and decides things, before conditionals or loops enter the picture at all. Control flow follows, if/elif/else, while loops, for loops, closed out by the first of two in-class exams.

Data structures get taught in two separate passes. The first covers Python's own built-in structures, lists, tuples, dictionaries, sets, alongside functions, lambda expressions, map/filter/reduce, basic recursion, and object-oriented programming, classes, inheritance, encapsulation, closed out by the second exam. The second pass, after that exam, covers the structures usually built by hand rather than reached for off the shelf, stacks, queues, and linked lists, implemented in Python rather than imported, alongside searching, sorting, Big O notation, and basic error handling and debugging.

NumPy, Pandas, and matplotlib, the libraries the three graded projects lean on hardest, get one combined lecture near the end of the semester, week 13 of 16, well after the second and third projects were already assigned. The course's own sequencing puts library fluency after the projects that need it, closer to working it out from documentation than applying a lecture directly. The final full week turns to databases, SQL, and accessing web content, material the syllabus's own learning objectives list but that arrives only in the semester's last stretch.

## What I actually built

Project 1, a Travel Budget Planner, computes total trip cost across five countries, Canada, Peru, Australia, India, and France, combining airfare, hotel tier, food, and optional attractions from dictionary lookup tables. The assignment restricted the submission to a single script: no functions, no file I/O.

Project 2 framed the assignment as work for "a quantitative developer working in a hedge fund," comparing two trading strategies' daily returns. The task: implement, from scratch, without Python's `statistics` module, the sample mean, the sample standard deviation, and a two-sample significance score,

\[
\text{score} = \frac{\bar{A} - \bar{B}}{\sqrt{\frac{S_A^2}{n_A} + \frac{S_B^2}{n_B}}}
\]

Welch's t-statistic, taught without ever being named as one.[^welch-df] My submission includes a hardcoded critical-value lookup table, keyed by degrees of freedom and confidence level, so the program returns an actual yes-or-no verdict on which strategy performs better at a chosen confidence level, not just a raw number.

Project 3 is pandas-based exploratory data analysis on a daily O'Hare weather dataset, columns for max, min, and average temperature, wind, precipitation, and snowfall. The assignment required inspecting the table, filtering rows by condition, and answering short analysis questions: which day had the highest max temperature, the most snow, how many days had measurable snowfall.

[^welch-df]: My degrees-of-freedom calculation uses the simpler pooled formula, `n1 + n2 - 2`, rather than the Welch-Satterthwaite approximation a textbook-exact version would use. The score formula itself is exact; the degrees-of-freedom step is a simplification.

## Performance

All three projects survive as complete, working code, not just prompt responses.[^recovery] Project 2 goes past the minimum ask: the assignment only requires a significance score, and the submission adds a full critical-value table and a plain-language verdict on top of it.

[^recovery]: The course's own local folder shows all three Projects as blank prompt PDFs; the actual submitted code was recovered separately from local editor history, not preserved in the original folder.

## Where this shows up elsewhere

Project 2's formula is the same two-sample significance test used throughout my STAT381 and STAT481 coursework, and the same reasoning, a mean difference scaled by pooled variability and sample size, compared against a threshold, drives significance testing in my independent quant research. An intro programming assignment, framed as a hedge-fund exercise, turned out to be teaching the exact tool I'd use for statistical work a year later.
